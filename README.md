# Ledger World globe

Open `index.html` in a modern browser. No installation, server, wallet, or build step is required.

- The globe orientation is fixed. Scroll or use +/− to zoom; click or tap to select.
- Select Australia or use **Focus Australia**.
- Select one of the three fictional AMM pools.
- **Enter country grid** opens the conceptual Australia grid. Select a cell, then close with × or Escape.
- Keyboard: focus the globe and use +/− or Enter to focus Australia.

The browser loads detailed country borders from https://github.com/johan/world.geo.json when online. The bundled map uses intentionally simplified geography when that request fails. Grid cells are conceptual, not real parcels. All liquidity amounts are fake.

This prototype is independent of MONK/MONKnopoly and has no blockchain integration or deployment.
